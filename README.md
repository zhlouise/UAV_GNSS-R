Repository for processing and experimenting with GNSS‑R (Global Navigation Satellite System - Reflectometry) data collected from UAVs (Unmanned Aerial Vehicles / drones).

This project contains tools and algorithms to process and analyze GNSS‑R observations from UAV platforms equipped with a dual-antenna RL setup. An addition set of sample data is also included. The goal is to develop reproducible processing pipelines and exploration code for research and prototyping.

**Project overview**
- GNSS‑R leverages reflected signals from GNSS satellites to retrieve properties of the reflecting surface (e.g., sea state, soil moisture, surface roughness).
